# CPI Inflation Analysis — Excel Case Study

Excel case study analyzing India's Consumer Price Index (CPI) inflation across sectors, categories and regions — from the **Introduction to Analytics & Excel** module (Data Analytics program, Coding Ninjas).

## Workbook

`CPI_Inflation_Case_Study.xlsb` — the completed analysis workbook: raw data, missing-value handling, and question-wise analysis sheets covering:

- Monthly and annual CPI trend analysis (2013–2023, Rural / Urban / Combined)
- Sectoral variation: food & beverages, pan/tobacco/intoxicants, fuel & light, housing, clothing & footwear
- Regional variation: urban vs rural
- Year-on-year inflation computation
- Visualizations: heat maps, slicers, pivot charts

## Tools

Microsoft Excel — pivot tables, pivot charts, slicers, conditional formatting, YoY formulas.
